# e2e-critic regression fixtures

This directory holds the regression fixtures and integration test for the
`e2e-critic` sub-agent (`.claude/agents/e2e-critic.md`). The critic is
the qualitative half of PRD-0016's per-slice E2E gate (ADR-0014); these
fixtures lock in the canonical bug it must catch — the empty-canvas
regression from PRD-0015 / 0015-01.

## Fixtures

| File | What it represents |
| --- | --- |
| `empty-canvas.png` | The historical empty-canvas regression: race surface mounted, stat bar visible at the top, canvas area below collapsed to a black void with no boat, no lane markings, no start line. The critic must return a `severity: blocker` finding here. |
| `race-canvas-visible.png` | A reference "good" frame: same stat bar, plus a horizontal lane band and a small bright rectangle near the left edge representing the user boat at the start line. The critic should *not* return a `severity: blocker` finding on this image alone. |

Both PNGs are hand-built synthetic — not screenshots of the real app — so
the regression test is fully self-contained and does not depend on a
running backend, dev server, or historical git revision. Each file is
~650 bytes (well under the 10 KB scope cap).

## How the fixtures were produced

The fixtures are generated by `make-fixtures.mjs` in this directory,
which writes raw RGBA pixels through Node's built-in `zlib` deflate to
produce a minimal valid PNG (no `pngjs` or `sharp` dependency). Re-run:

```sh
node web/tests/e2e/critic-regression/make-fixtures.mjs
```

The script is deterministic; re-running it produces byte-identical files.

## Regression test

`critic-regression.mjs` is a plain Node script, run with `node`, not a
Playwright spec. It must not be named `*.test.mjs` or `*.spec.*`: that
matches Playwright's default `testMatch`, and because the script runs on
import and calls `process.exit`, loading it would terminate the whole
`playwright test` run before any test starts (CI hit exactly this). A
`testIgnore` in the config is not enough, since a project-level
`testIgnore` replaces the top-level one.

`critic-regression.mjs` invokes the `e2e-critic` sub-agent against
`empty-canvas.png` and asserts:

1. The sub-agent exits with a non-zero status code.
2. Its stdout is parseable JSON matching the schema in the sub-agent
   definition.
3. `findings[]` contains at least one entry with `severity: "blocker"`
   whose `summary` or `detail` references the missing boat or empty
   canvas.

Run:

```sh
node web/tests/e2e/critic-regression/critic-regression.mjs
```

### Invocation mechanism

The test invokes the sub-agent via the `claude` CLI:

```sh
claude -p --agent e2e-critic --output-format json < input.json
```

If `claude` is not on `PATH`, or the environment does not support
non-interactive sub-agent invocation, the test prints a `SKIP` line
with a clear TODO and exits 0. The TODO is: wire the test runner into
the same mechanism the AFK loop will use to invoke the critic
(documented in PRD-0016 §Implementation Decisions but not yet
finalised at the time of 0016-03).
